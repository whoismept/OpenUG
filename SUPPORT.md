# Support

## Where to ask

- **Reproducible engine bug:** use the Bug Report issue form.
- **File-format observation or decoder research:** use the Format Research issue form.
- **Small, well-scoped contribution:** look for issues labelled `help wanted`.
- **General usage question:** first read the README and `docs/FORMATS.md`; open an issue only when the answer may improve project documentation.

Issues are for actionable, public project work. Do not post game assets, personal paths, passwords, private logs, or sensitive personal information.

## Scope

OpenUG2 is an independent, clean-room engine reimplementation. It does not provide game assets, executable patches, DRM bypasses, or support for redistributed game data. You need a legally acquired copy of the original game data to run it.
